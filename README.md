# Resume Helper

Resume Helper 是一个面向中文技术简历的 AI Skill。它会分析用户选择的软件、硬件、科研或工程项目，从代码、配置和项目文档中提取可验证的信息，并整理成适合放入简历的项目经历。

## 主要能力

- 识别项目背景、核心模块、总体架构和实际效果。
- 提取语言、框架、数据库、中间件、技术概念及协议栈。
- 根据项目内容推断合理的职责定位，避免夸大个人贡献。
- 生成不超过100字的项目介绍，以及3至4条不超过80字的项目亮点。
- 优先使用可验证的数字，禁止编造性能提升、用户规模或团队数据。
- 在生成最终内容前，要求用户提供项目起止时间，不从文件或Git历史猜测。

## 安装目录

Codex 技能目录结构：

```text
resume-helper/
├── SKILL.md
├── README.md
├── RESUME_EXAMPLE.md
└── agents/
    └── openai.yaml
```

Claude Code 可将整个目录复制到：

```text
~/.claude/skills/resume-helper/
```

## 使用方式

在支持 Skills 的环境中调用 `$resume-helper`，并选择需要分析的项目。例如：

```text
使用 $resume-helper 分析我选择的项目，提取适合中文后端开发简历的项目经历。
```

技能会先确认项目和项目时间，再检查项目文件并按以下结构输出：

```text
项目名称：<名称>    项目职责：<职责>    项目时间：<时间>
技术栈：<技术关键词>
项目介绍：<背景、方法与效果>
项目亮点：
- <亮点一>
- <亮点二>
- <亮点三>
```

完整的虚构输出示例见 [RESUME_EXAMPLE.md](RESUME_EXAMPLE.md)。

## 隐私与真实性

- 示例内容使用虚构项目，不包含真实用户项目数据。
- 输出只引用项目文件或用户陈述中能够验证的信息。
- 不应在结果中暴露凭据、内部地址、密钥或敏感实现细节。
- 若无法确认某项个人贡献，应使用保守措辞或向用户补充确认。

## 文件说明

- `SKILL.md`：技能触发条件、分析流程、写作规则与输出格式。
- `RESUME_EXAMPLE.md`：经过脱敏的虚构简历项目生成示例。
- `agents/openai.yaml`：Codex 技能界面元数据。
